# 2048 Game — Classic Puzzle Web Application

An interactive browser-based implementation of the classic **2048** sliding tile puzzle game. Combine tiles with matching numbers to reach the ultimate goal: the **2048** tile!

## Live Preview

Experience the live game: [Click here to play 2048 Demo](https://Chempik120.github.io/2048_game/)

## Technologies Used

### Core

* **HTML5** – Semantic game board structure

* **SCSS / CSS3** – Custom styling, layout grid, and responsive design

* **JavaScript (ES6+)** – Game logic, state management, tile movement algorithms, and event handling

### Build Tools & Quality

* **Vite / Webpack** – Module bundling and hot reloading

* **ESLint** – Code formatting and quality standards

## Key Features

* **Classic Gameplay:** Slide tiles using keyboard arrow keys to merge identical numbers.

* **Score Tracking:** Real-time score counter updating with every successful tile merger.

* **Game State Overlay:** Dynamic messages showing start prompts, win conditions (upon reaching 2048), and game over states.

* **Restart Option:** Easily restart the board at any time using the "Start" button.

* **Responsive Design:** Clean, centered grid board adaptable across screen sizes.

## How to Play

1. Click the **Start** button to initialize the grid with random tiles.
2. Use your **Arrow Keys** (Up, Down, Left, Right) to move all tiles in the chosen direction.
3. When two tiles with the same number touch, they **merge into one** with double the value.
4. Try to create a tile with the value **2048** to win!

## Getting Started

Follow these simple steps to set up and run the game locally:

### 1. Clone the repository:

```bash
git clone https://github.com/Chempik120/2048_game.git
cd 2048_game
```

### 2. Install dependencies:

```bash
npm install
```

### 3. Run the project locally:

```bash
npm start
```

*Or open `index.html` directly using a local server tool like Live Server.*
